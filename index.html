Editar anotação
Sincronia e dados

As anotações ficam gravadas num arquivo JSON dentro de um repositório privado do seu GitHub. Cada máquina (casa, trabalho, celular) usa a mesma configuração e vê as mesmas notas. Sem servidor, sem VM.

Atenção de segurança: o token é guardado no armazenamento local deste navegador, nesta máquina. Qualquer pessoa com acesso ao seu usuário do Windows, ou uma extensão de navegador maliciosa, pode lê-lo. Use um token fine-grained limitado a este único repositório, apenas com Contents: Read and write, e com data de expiração. No notebook do trabalho, prefira um token separado e revogue-o quando não precisar mais (GitHub → Settings → Developer settings → Personal access tokens).
